# Solar Roof AI frontend

See the [root README](../README.md) for the development setup, backend requirements, and configuration. The web app uses Next.js App Router and expects the FastAPI service for upload, detection, and viewing saved result files.

From this directory, run `npm ci` and `npm run dev` for local development. Use `npm run lint -- --max-warnings 0` and `npm run build` before opening a pull request.
